# Son en langue française pour répéteur svxlink.
J’ai fait des modifications et des améliorations afin qu'ils soient compatibles avec les répéteurs SVXLink du Saguenay.

Pour ajouter les fichiers de sons en langue français, il faut suivre ses étapes si dessous:
```
cd /usr/share/svxlink/sounds
```
```
sudo git clone https://github.com/RadioamateursduFjord/svxlink-sounds-qc_QC.git qc_QC
```
Un dossier nommer qc_QC sera créé où il sera installé les fichiers en langue français.
